# Next step

Whenever a skill stops or finishes, in the main session, end your message with one line saying what comes next, so the user never has to guess which command picks the work up:

> **Next:** `/ourkit-plan`, to decide how to build it. I'll start once you agree to the spec.

- Name the skill to run, or the action that's the user's, such as "review and merge the PR".
- Say in a few words what it does.
- Say whether it's waiting for the user, and for what. If you'll carry on by yourself, say so.
- If something blocks the work, the next step is what unblocks it, such as answering a question, followed by the skill to run after that.

Each skill's hand-over section names its next step. In Hands-off, put the line at the end of the report. Subagents don't write it.
